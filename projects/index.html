Computational neuroscience

BMTool

An all-in-one Python package that makes it easier to develop model neural networks in BMTK and NEURON. Install it with pip install bmtool.

Source on GitHub PyPI User guide (PDF)

SimAgent

Connects a laptop directly to Neuroscience Gateway resources to run NEURON network simulations. It has two core functions. Automated job submission is a point-and-click interface that takes any NEURON or Python program directory, submits it to run remotely, and watches it to completion with live updates. Parameter sweep does the same while changing marked sections of code on each run, so you can give a parameter a range of values, run the simulations in parallel, and pick the best output. It supports the NSG-R REST API and SSH connections to servers running Slurm.

Source and Windows executable Video, part 1 Video, part 2 On CyNeuro.org

SimBuilder

A desktop application for building large-scale networks in NEURON. It uses Marianne J. Bezaire’s CA1 model as a backend and generalizes the process so users can specify their own network requirements.

Source and Windows executable On CyNeuro.org

CNN-Fold

For my master’s thesis project I applied convolutional neural networks to protein fold recognition, under the direction of Dr. Jianlin Cheng. The program implements a convolutional network in DL4J on a one-dimensional dataset provided by Dr. Cheng.
